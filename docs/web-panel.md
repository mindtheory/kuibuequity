# Web 面板设计（client 半区）

> 目标：在 DSH Web GUI 左侧插件栏提供「跬步量化」入口，主区渲染三象限驾驶舱。
> 参考 dsh-super-agents / dsh-plugin-stock-x / dsh-leekbox 的成熟做法，并针对量化场景优化。

## 1. 挂载方式（与 dsh-super-agents 同构，已验证可行）

- 浏览器半区 `client.js`：`window.__ModuleLoader__.load`，`inject = ["slots", "locale"]`
- 侧栏入口：`slots.inject("sidebar.panellist")` 注册图标（order=27，超级智能体=26 之后）
- 主区页面：`slots.inject("main")` 注册面板页
- 铁律：绝不在等待客户端服务时 `ctx.inject()`（会卡死宿主启动）；所有宿主 API 访问都包 try/catch，面板永不向上抛错
- 节点半区：`ctx.inject(["webServer"])` 注册 `/api/kuibuequity/*` 只读+受控写路由；loopback 守卫（`allowLanState=false` 时仅本机）

## 2. 与参考插件的差异（优化点）

| 参考插件做法 | 本面板优化 | 理由 |
| :-- | :-- | :-- |
| 单页长滚动（super-agents） | 顶部 Tab 分区：总览 / 持仓 / 指令单 / 个股体检 / 复盘 | 量化信息密度高，滚动找不如 Tab 直达 |
| 纯文本状态 | 状态灯 + 进度条 + 迷你 SVG 走势图 | 成本转负进度、胜率 vs 要求胜率、情绪总闸都是"一眼型"信息 |
| 手动刷新 | 5s 轮询 + 手动刷新按钮 + stale 徽标 | 行情有 as_of，陈旧必须可见（P7） |
| 内联样式散落 | 全部 CSS 类 + 继承宿主前景色 + rgba 边框 | 自动适配宿主明暗主题，不硬编码颜色 |
| 表单直接提交 | 写操作（录入成交）先展示回执再落库；错误码原样展示 | 与"诚实的失败"一致，UI 不粉饰 |

## 4. API（节点半区，全部 JSON）

| 路由 | 方法 | 说明 | 离线可用 |
| :-- | :-- | :-- | :-- |
| `/api/kuibuequity/state` | GET | 三象限账户+持仓+契约+费率（账本） | ✅ |
| `/api/kuibuequity/quote?symbol=` | GET | 实时快照 | ❌ 断网返回 ERR-DATA-001 |
| `/api/kuibuequity/sentiment` | GET | 情绪总闸（沪深300 vs MA5） | ❌ |
| `/api/kuibuequity/plan` | POST | {mode,symbol,days?} → 指令单+条件单 | ❌ |
| `/api/kuibuequity/trade` | POST | 录入成交（stable 自动锁契约） | ✅ |
| `/api/kuibuequity/check` | POST | {symbol} stable 持仓体检 | ❌ |
| `/api/kuibuequity/review?period=&quadrant=` | GET | 复盘统计 | ✅ |

错误统一 `{ok:false,code,message}`；UI 对 `ERR-DATA-*` 显示"行情源不可达"而非崩溃。

## 5. 安全

- 只读为主；唯一写 = 录入成交（本地账本，不接券商）
- loopback 守卫：`allowLanState=false`（默认）时非本机请求 403
- 所有输出页脚固定免责声明
