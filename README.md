# 跬步量化 · kuibuequity

> 不积跬步，无以至千里。

一个 [DeepSeek Harness（DSH）](https://github.com/mindtheory) 插件：帮**普通人**把股票账户管起来。
它不预测涨跌、不荐股，而是把投资拆成三种互不混淆的玩法，每种玩法配一套**事前写死、事中不可临时更改、事后可复盘**的规则——
插件负责计算、生成指令单、盯住红线，你只负责在开盘时把指令单敲进券商。

**核心立场：这是一个"纪律执行器"，不是"预测器"。**

## 三象限

| 象限 | 代号 | 一句话 | 周期 | 对抗的人性 |
| :-- | :-- | :-- | :-- | :-- |
| **长期** | `long` | 高股息底仓 + 网格摊薄，把持仓成本做成**负数**（典型：工商银行） | 3~10 年 | 下跌时的恐慌 |
| **稳定** | `stable` | 赚 1%~5% 就走，不猜顶；条件单前置，落袋为安 | ≤20 交易日 | 贪婪与不甘 |
| **短线** | `short` | 次日强势打分，**最多拿 5 天**，到期无条件清仓 | 1~5 交易日 | 上头、套牢装死 |

三个象限**资金物理分账**，禁止跨象限"救火"。

## 它做与不做

| ✅ 做 | ❌ 不做 |
| :-- | :-- |
| 只读行情（东方财富免 Key 接口） | 券商实盘接口、资金接口、凭据存储 |
| 网格参数 / 成本转负 ETA / 分红摊薄模拟 | 任何"保证收益""预测涨停准确率"话术 |
| 1~5% 自适应止盈契约 + 券商条件单参数导出 | 盘中盯盘喊单（只在收盘后出次日计划） |
| 短线候选打分 + 情绪总闸 + 5 日强制离场 | 分钟级高频、两融、期权期货 |
| 无未来函数回测 + 期望值自检（负期望直接劝阻） | 代客理财、收费荐股 |
| 象限账本 + 风控闸门 + override 审计 | 替你下单（自动 = 冷静时替冲动的你挂好条件单） |

## 快速开始

```bash
# 1. 安装到 DSH（web profile 示例）
dsh plugin --profile web add kuibuequity

# 2. 重启 dsh web 后，对 AI 说：
#    "用 kb_longterm 看看 601398 的网格参数和成本转负 ETA"
#    "用 kb_stable 给 000001 做一次建仓体检"
#    "用 kb_short 看今天的短线候选池"
```

本地开发调试（热加载，无需反复安装）：

```bash
git clone https://github.com/mindtheory/kuibuequity.git && cd kuibuequity
node --test test/            # 跑全部单元测试
dsh --patch ./cordis.patch.yml --profile web   # 覆盖层热加载
```

## 工具一览

| 工具 | 干什么 |
| :-- | :-- |
| `kb_market` | 行情：实时快照 / 日 K / 分红送配 |
| `kb_account` | 象限账本：建账、录入成交、查成本、跨象限调拨（写审计） |
| `kb_longterm` | 长期：网格参数、成本转负 ETA、分红摊薄模拟 |
| `kb_stable` | 稳定：建仓契约、持仓体检、次日指令单、条件单 CSV 导出、期望值自检 |
| `kb_short` | 短线：候选池打分、离场提醒、情绪总闸状态 |
| `kb_backtest` | 统一回测（无未来函数 / T+1 / 整手 / 涨跌停 / 费用） |
| `kb_risk` | 风控闸门、红线查询、override 申请与审计 |
| `kb_review` | 周/月复盘：胜率、盈亏比、override 清单、按象限纪律遵守率、短线超期未离场清单 |

## 工程原则

1. **纯函数内核**：指标/成本/回测/策略不依赖 DSH、不依赖网络，`node --test` 独立可验
2. **无未来函数**：信号在第 i 根 K 线收盘确认，第 i+1 根成交
3. **成本口径唯一**：费用公式只写在 `src/costs.js`，与券商交割单可逐笔对账
4. **事前承诺 > 事中判断**：契约锁定，改需 override + 理由，全部进审计日志
5. **诚实的失败**：数据不足、负期望、情绪退潮 → 明确拒绝，绝不伪造成交
